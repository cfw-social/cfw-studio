# r-inspired-reel learnings

Lessons a new user can apply. Add a dated line when a run teaches something.

- Write the script from the format numbers only. A writer who has read the reference tends to echo its phrases.
- Check the script's shape before the overlap check: a script with the right beats and word count rarely needs a long rewrite.
- Delete the reference transcript as soon as the script has passed. Nothing later needs it.
- Set the narration speed before the paid render. A voice that runs slow or fast moves the reel outside the length window, and a new narration is a new charge.
