# r-your-recipe

Replace this template when you add a real recipe. This file is the guiding document: when to use the recipe, how the blocks fit, and any coordination the agent needs.

## When to use

One or two sentences, plus what the final output looks like.

## Inputs

List the inputs from `recipe.yaml` (the union of the blocks' required inputs, and any optional settings).

## How the blocks fit

1. Run the first block with the recipe inputs it needs.
2. Pass each block's outputs to the next block.
3. Produce the declared final output.

## Checks

Name what a successful recipe run looks like.
